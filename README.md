# Job Market Intelligence Dashboard

### End-to-End Data Analytics Project | Python · PostgreSQL · SQL · Power BI

An end-to-end analytics project that processes job-posting data through Python and PostgreSQL and delivers an interactive Power BI dashboard for analyzing job demand, skills, salary patterns, locations and skill gaps.

## Project Overview

This project transforms raw job-posting data into an analytical dataset and interactive dashboard.

The workflow follows:

**Raw Data → Python/Pandas → PostgreSQL → SQL Analysis → Power BI**

## Business Questions

The project aims to answer questions such as:

- Which skills are most frequently requested by employers?
- Which locations have the highest job demand?
- How does salary vary across different skills?
- Which skills are associated with higher-paying opportunities?
- What skills are missing from my current skill set?
